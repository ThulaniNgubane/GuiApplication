The Application has two window forms(starting page and the main app) and two classes that contain the codes for the app. 
The first window form shows a logo, a background picture, a small summery of what the app is about, and  a start button for the user to press and start the app.
The starting page class contains code for that makes the app to go on the second window form(Main App)
The Second window form contain a logo, input box and a message box, and a send button for the user to click after inputting the text.
The main app class contain the codes to play the greeting sound introducing the app.
The main app class also contain the codes random responses, memory, sentiments  detected and real conversation flows.
